02 · 실험 파이프라인

세 단계, 하나의 계약
STAGE 1 · 진행 중
GATv2
노드 단위 지도학습. 정류장별 수요 예측 + 임베딩 생성.
INPUT snapshot .pt (x, edge_index, y)
OUTPUT embedding [N, D] + pred [N, 3]
→
STAGE 2 · 예정
MAPPO
다중 에이전트 PPO. GATv2 임베딩을 관측으로 받아 의사결정 학습.
INPUT frozen embedding cache
OUTPUT policy π(a|s)
→
STAGE 3 · 예정
Qwen
LLM 레이어. 설명 생성 / 상위 플래너 / 리워드 모델 중 역할 TBD.
INPUT state text + π action
OUTPUT TBD per role
설계 원칙
GATv2 체크포인트는 val_loss가 아니라 MAPPO 입력 계약으로 평가한다.
