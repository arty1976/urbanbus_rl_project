# 데이터 소스 레지스트리 (Source Registry)

본 문서는 대중버스의 동적 운영 연구 및 교통카드 데이터 파이프라인 기초 구성에 활용되는 원천 데이터 목록을 명시합니다.

## 1. 대구광역시 마스터 데이터
* **Daegu stop master**: 대구광역시 버스 정류장 마스터 데이터 (정류장 ID, 좌표, 기본 명칭 등).
* **Daegu route master**: 대구광역시 버스 노선 마스터 데이터 (노선 ID, 기존 고정 노선 정보 등). 동적 라우팅 알고리즘의 기초 벤치마크 및 변형 기준으로 활용됩니다.
* **Daegu route spatial links**: 기존 노선의 정류장 간 물리적 이동 경로를 담은 공간 링크 데이터. 
* **Daegu real-time bus API**: 버스 실시간 도착 및 위치 정보 API. 동적 운영 전환 시 차량의 실시간 상태를 파악하는 용도로 사용됩니다.

## 2. STCIS (교통카드빅데이터 통합정보시스템) 데이터
* **STCIS OD**: 승객들의 출발지와 도착지(Origin-Destination) 통행량 데이터. 동적 셔틀이나 버스의 수요 예측 및 노선 최적화의 핵심 근거 자료입니다.
* **STCIS stop/route indicators**: 기존 정류장별, 노선별 승하차 지표 (배차 간격 대비 승하차 횟수, 혼잡도 등).

## 3. 자체 보유 데이터
* **user-owned raw smart-card data if available**: 연구진이 자체적으로 보유한 원천 스마트카드 결제 및 태그 데이터 로그. 가용할 경우, 위 STCIS 집계 데이터보다 더 미시적인(Micro) 승객 패턴 분석에 활용됩니다.
